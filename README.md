# Yaduwanshi Child Water — Version 9

GitHub-ready mobile-first PWA for RO water business management.

## Features
- Dashboard: customers, daily jars, sales, outstanding
- Customer add + **Edit Customer**
- Daily delivery entry with jar × customer rate
- Monthly bill with print / Save PDF and WhatsApp share
- Payment entry: Cash, Online, UPI, Bank
- Outstanding / customer ledger
- Area / Route management
- Driver / Staff records
- Jar / stock management
- Monthly sales reports
- JSON Backup / Restore
- LocalStorage data persistence
- Installable PWA / offline cache

## Run on GitHub Pages
1. Upload all files to a GitHub repository.
2. Go to **Settings → Pages**.
3. Select **Deploy from branch**, branch `main`, folder `/root`.
4. Open the generated Pages URL on Android Chrome.
5. Use **Add to Home screen / Install app**.

This build includes Daily Entry +/- jar controls and Cash/Pending payment handling. Data is currently stored in browser localStorage; use Backup / Restore before changing devices or clearing browser data. Cloud sync/login is not included yet.
